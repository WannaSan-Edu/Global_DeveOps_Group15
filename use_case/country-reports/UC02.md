# UC02: Countries by Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC02 |
| Use Case Name | Countries by Continent |
| Category | Country Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display countries belonging to a continent selected by the Organisation User.

## 3. Preconditions

- The system and database are available.
- Valid continent information is available.

## 4. Trigger

The Organisation User selects the countries-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays the available continents.
3. The user selects a continent.
4. The system validates the selection.
5. The system retrieves countries matching the selected continent.
6. The system sorts the results by population in descending order.
7. The system displays the country information.

## 6. Alternative and Exception Flows

- **A1: Invalid selection.** The system requests a valid continent.
- **A2: No matching countries.** The system displays a no-results message.
- **E1: Database error.** The system displays an appropriate error message.

## 7. Postconditions

The countries matching the selected continent are displayed, or an appropriate message is provided.
