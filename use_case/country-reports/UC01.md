# UC01: All Countries in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC01 |
| Use Case Name | All Countries in the World |
| Category | Country Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display all countries stored in the database, including their geographical information and population.

## 3. Preconditions

- The Population Reporting System is running.
- The MySQL database is accessible.
- Country records are available in the database.

## 4. Trigger

The Organisation User selects the report for all countries in the world.

## 5. Main Success Flow

1. The Organisation User selects the all-countries report.
2. The system retrieves country records from the `Country` table.
3. The system obtains the country code, name, continent, region, population, and capital code where available.
4. The system sorts the records by population in descending order.
5. The system displays the report.

## 6. Alternative and Exception Flows

- **A1: No records found.** The system displays a message indicating that no country records are available.
- **E1: Database connection failure.** The system displays an appropriate error message and does not present incomplete results as a successful report.

## 7. Postconditions

The country report is displayed, or an appropriate message explains why the report cannot be generated.
