# UC32: Language Speakers and Percentage of World Population

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC32 |
| Use Case Name | Language Speakers and Percentage of World Population |
| Category | Language Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To estimate the number of speakers and the percentage of the represented world population for Chinese, English, Hindi, Spanish, and Arabic using the available database information.

## 3. Preconditions

- The system and database are available.
- Country population records exist.
- Language records and their percentage values are available in the `CountryLanguage` table.
- The project requirements define the calculation method.

## 4. Trigger

The user selects the language-speaker report.

## 5. Main Success Flow

1. The user selects the report.
2. The system identifies Chinese, English, Hindi, Spanish, and Arabic in the language records.
3. The system retrieves the relevant country population and language percentage values.
4. The system estimates speakers for each language in each country using the agreed calculation method.
5. The system aggregates the country-level estimates for each language.
6. The system calculates each language's estimated speakers as a percentage of the represented world population.
7. The system sorts the results by estimated number of speakers in descending order.
8. The system displays the language name, estimated number of speakers, and calculated percentage.

## 6. Alternative and Exception Flows

- **A1:** A requested language is not found. The system identifies the missing language.
- **A2:** Country population or language percentage data is missing. The system handles incomplete data according to the agreed rules.
- **A3:** Language percentage values are invalid. The system excludes or flags invalid values according to the agreed validation rules.
- **A4:** The represented world population is zero or unavailable. The system does not calculate an invalid percentage.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The language report is displayed with the available language data and calculated estimates.

## 8. Calculation Notes

Where this method is required by the coursework:

- Estimated speakers in a country = Country population × Language percentage / 100.
- Estimated speakers worldwide for a language = Sum of the eligible country-level speaker estimates.
- Percentage of represented world population = Estimated worldwide speakers for the language / Represented world population × 100.

The calculations depend on the meaning and validity of the database's language percentage values. Language groups can overlap because one person may speak more than one language. Therefore, language percentages must not be added together as if every person speaks only one language.

The report should describe the results as estimates rather than exact current speaker counts.
