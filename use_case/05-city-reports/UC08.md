# UC08: Cities by Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC08 |
| Use Case Name | Cities by Continent |
| Category | City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display cities located in a selected continent.

## 3. Preconditions

The system and database are available, and city and country data exist.

## 4. Trigger

The user selects the cities-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available continents.
3. The user selects a continent.
4. The system validates the selection.
5. The system retrieves cities associated with countries in that continent.
6. The system sorts cities by population in descending order.
7. The system displays the city name, country, district, and population.

## 6. Alternative and Exception Flows

- **A1:** Invalid continent. The system requests a valid selection.
- **A2:** No matching cities. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

Cities belonging to the selected continent are displayed, or an appropriate message is provided.
