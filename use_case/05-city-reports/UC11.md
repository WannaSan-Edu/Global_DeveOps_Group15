# UC11: Cities by District

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC11 |
| Use Case Name | Cities by District |
| Category | City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display cities recorded within a selected district.

## 3. Preconditions

The system and database are available, and city district information exists.

## 4. Trigger

The user selects the cities-by-district report.

## 5. Main Success Flow

1. The user selects the report.
2. The system obtains the available district values.
3. The user selects a district.
4. The system validates the selection.
5. The system retrieves cities matching the selected district.
6. The system sorts cities by population in descending order.
7. The system displays the results.

## 6. Alternative and Exception Flows

- **A1:** Invalid district. The system requests a valid selection.
- **A2:** No matching cities. The system displays a no-results message.
- **A3:** The selected district name occurs in multiple countries. If necessary, the system requests additional information to identify the intended district.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

Cities matching the selected district are displayed, or an appropriate message is provided.
