# UC09: Cities by Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC09 |
| Use Case Name | Cities by Region |
| Category | City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display cities located in a selected geographical region.

## 3. Preconditions

The system and database are available, and city and country data exist.

## 4. Trigger

The user selects the cities-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available regions.
3. The user selects a region.
4. The system validates the selection.
5. The system retrieves cities associated with countries in that region.
6. The system sorts cities by population in descending order.
7. The system displays the results.

## 6. Alternative and Exception Flows

- **A1:** Invalid region. The system requests a valid selection.
- **A2:** No matching cities. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

Cities within the selected region are displayed, or an appropriate message is provided.
