# UC18: Capital Cities by Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC18 |
| Use Case Name | Capital Cities by Continent |
| Category | Capital City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display capital cities belonging to countries within a selected continent.

## 3. Preconditions

The system and database are available, and the required country and capital city records exist.

## 4. Trigger

The user selects the capital-cities-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available continents.
3. The user selects a continent.
4. The system validates the selection.
5. The system retrieves countries belonging to that continent.
6. The system identifies their capital cities using the country capital references.
7. The system sorts capital cities by city population in descending order.
8. The system displays the results.

## 6. Alternative and Exception Flows

- **A1:** Invalid continent. The system requests a valid selection.
- **A2:** No matching capital cities. The system displays a no-results message.
- **A3:** Missing capital references. The system excludes or identifies incomplete records according to the agreed reporting rules.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

Capital cities associated with the selected continent are displayed, or an appropriate message is provided.
