# UC23: Population Distribution by Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC23 |
| Use Case Name | Population Distribution by Continent |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display population distribution information for each continent, including total country population and recorded city population.

## 3. Preconditions

The system and database are available, and the required country and city population data exists.

## 4. Trigger

The user selects the population-distribution-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country population data grouped by continent.
3. The system calculates total country population for each continent.
4. The system calculates the sum of recorded city populations for countries in each continent.
5. The system calculates the difference between country population and recorded city population where the data supports this calculation.
6. The system calculates percentages using the agreed calculation rules.
7. The system displays the population distribution report.

## 6. Alternative and Exception Flows

- **A1:** No population data is available. The system displays a no-results message.
- **A2:** Population values are missing or invalid. The system identifies incomplete data and avoids presenting unsupported calculations.
- **A3:** Total population is zero. The system does not divide by zero and identifies the percentage as unavailable.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The population distribution report is displayed with supported calculations and clearly identified limitations.
