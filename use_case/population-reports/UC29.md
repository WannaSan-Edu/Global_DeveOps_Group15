# UC29: Population by Country

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC29 |
| Use Case Name | Population by Country |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the recorded population of each country.

## 3. Preconditions

The system and database are available, and country population data exists.

## 4. Trigger

The user selects the population-by-country report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country names and their population values.
3. The system validates the available population data.
4. The system sorts the country records by population in descending order if ranking is required.
5. The system displays each country and its population.

## 6. Alternative and Exception Flows

- **A1:** No country records are available. The system displays a no-results message.
- **A2:** Population data is missing or invalid. The system handles incomplete records according to the agreed reporting rules.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The country population report is displayed, or an appropriate message is provided.
