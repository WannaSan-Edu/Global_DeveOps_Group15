# UC30: Population by District

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC30 |
| Use Case Name | Population by District |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To calculate and display the recorded city population total for each district.

## 3. Preconditions

The system and database are available, and city population and district data exists.

## 4. Trigger

The user selects the population-by-district report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves city names, district values, and population values.
3. The system groups city records by district.
4. The system calculates the sum of eligible city population values for each district.
5. The system displays the district names and calculated population totals.

## 6. Alternative and Exception Flows

- **A1:** No eligible city records are available. The system displays a no-results message.
- **A2:** Population values are missing or invalid. The system handles incomplete data according to the agreed rules.
- **A3:** District information is missing. The system identifies the incomplete records rather than assigning them to an unsupported district.
- **A4:** District names are ambiguous across countries. The system distinguishes them by country where required.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The district population report is displayed with the calculated totals.

## 8. Calculation Note

The reported total is the sum of the eligible city population values recorded for each district. It should not be assumed to represent the complete population of a district unless the database and project requirements support that interpretation.
