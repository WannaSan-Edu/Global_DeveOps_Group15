# UC25: Population Distribution by Country

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC25 |
| Use Case Name | Population Distribution by Country |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display population distribution information for each country, including total population and recorded city population.

## 3. Preconditions

The system and database are available, and country and city population data exists.

## 4. Trigger

The user selects the population-distribution-by-country report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country population records.
3. The system calculates the sum of recorded city populations associated with each country.
4. The system compares recorded city population with the country's total population.
5. The system calculates estimated non-city population where the data supports the calculation.
6. The system calculates the relevant percentages.
7. The system displays the population distribution report.

## 6. Alternative and Exception Flows

- **A1:** No country records are available. The system displays a no-results message.
- **A2:** City or country population data is missing. The system identifies incomplete records.
- **A3:** Total population is zero. The system avoids division by zero.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The country-level population distribution report is displayed with supported calculations.

## 8. Calculation Notes

Where permitted by the project requirements:

- City population percentage = Recorded city population / Total country population × 100.
- Estimated non-city population = Total country population - Recorded city population.
- Estimated non-city population percentage = Estimated non-city population / Total country population × 100.

These calculations depend on the completeness and meaning of the available city population records. They must not be presented as confirmed urban and rural population statistics without supporting data.
