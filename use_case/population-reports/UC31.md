# UC31: Population by City

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC31 |
| Use Case Name | Population by City |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the recorded population of individual cities.

## 3. Preconditions

The system and database are available, and city population data exists.

## 4. Trigger

The user selects the population-by-city report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves city names, country identifiers, district values, and population values.
3. The system validates the available population data.
4. The system sorts cities by population in descending order if required.
5. The system displays the city names and associated population information.

## 6. Alternative and Exception Flows

- **A1:** No city records are available. The system displays a no-results message.
- **A2:** Population data is missing or invalid. The system handles incomplete records according to the agreed rules.
- **A3:** City names are duplicated. The system displays additional identifying information, such as the country name.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The city population report is displayed, or an appropriate message is provided.
