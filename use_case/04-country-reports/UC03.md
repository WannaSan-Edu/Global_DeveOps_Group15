# UC03: Countries by Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC03 |
| Use Case Name | Countries by Region |
| Category | Country Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display countries belonging to a selected geographical region.

## 3. Preconditions

- The system and database are available.
- Region information exists in the database.

## 4. Trigger

The Organisation User selects the countries-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays the available regions.
3. The user selects a region.
4. The system validates the selection.
5. The system retrieves countries matching the selected region.
6. The system sorts the countries by population in descending order.
7. The system displays the results.

## 6. Alternative and Exception Flows

- **A1: Invalid region.** The system requests a valid region.
- **A2: No matching countries.** The system displays a no-results message.
- **E1: Database failure.** The system displays an appropriate error message.

## 7. Postconditions

The countries within the selected region are displayed, or the reason for unsuccessful retrieval is communicated.
