# UC06: Top N Populated Countries in a Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC06 |
| Use Case Name | Top N Populated Countries in a Region |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated countries within a selected region.

## 3. Preconditions

The system and database are available, and region data exists.

## 4. Trigger

The user selects the top-N countries-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available regions.
3. The user selects a region.
4. The system requests N.
5. The user enters a positive integer.
6. The system validates the inputs.
7. The system retrieves countries in the selected region.
8. The system sorts the results by population in descending order.
9. The system displays up to N countries.

## 6. Alternative and Exception Flows

- **A1:** Invalid region or N. The system requests valid input.
- **A2:** Fewer than N eligible countries. The system displays all eligible results.
- **A3:** No matching countries. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N country report for the selected region is displayed, or an appropriate message is provided.
