# UC04: Top N Populated Countries in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC04 |
| Use Case Name | Top N Populated Countries in the World |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated countries worldwide.

## 3. Preconditions

- The system and database are available.
- Country population data is available.

## 4. Trigger

The user selects the worldwide top-populated-countries report.

## 5. Main Success Flow

1. The user selects the report.
2. The system requests a value for N.
3. The user enters a positive integer.
4. The system validates the input.
5. The system retrieves country records with population data.
6. The system sorts the records by population in descending order.
7. The system returns up to N countries.
8. The system displays the results.

## 6. Alternative and Exception Flows

- **A1: Invalid N.** If N is empty, non-numeric, zero, or negative, the system requests a positive integer.
- **A2: Fewer than N eligible records.** The system displays all eligible records.
- **A3: No eligible records.** The system displays a no-results message.
- **E1: Database failure.** The system displays an appropriate error message.

## 7. Postconditions

The requested top-N country report is displayed, or the system explains why it cannot be generated.
