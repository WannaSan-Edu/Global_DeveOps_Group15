# UC14: Top N Populated Cities in a Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC14 |
| Use Case Name | Top N Populated Cities in a Region |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated cities within a selected region.

## 3. Preconditions

The system and database are available, and city and regional information exists.

## 4. Trigger

The user selects the top-N cities-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available regions.
3. The user selects a region.
4. The system requests N.
5. The user enters a positive integer.
6. The system validates the inputs.
7. The system retrieves eligible cities associated with the selected region.
8. The system sorts the cities by population in descending order.
9. The system displays up to N cities.

## 6. Alternative and Exception Flows

- **A1:** Invalid region or N. The system requests valid input.
- **A2:** Fewer than N eligible cities exist. The system displays all eligible cities.
- **A3:** No matching cities. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N city report for the selected region is displayed, or an appropriate message is provided.
