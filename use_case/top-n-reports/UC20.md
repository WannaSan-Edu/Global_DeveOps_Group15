# UC20: Top N Populated Capital Cities in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC20 |
| Use Case Name | Top N Populated Capital Cities in the World |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated capital cities worldwide.

## 3. Preconditions

The system and database are available, and valid capital city references and population data exist.

## 4. Trigger

The user selects the worldwide top-populated-capital-cities report.

## 5. Main Success Flow

1. The user selects the report.
2. The system requests N.
3. The user enters a positive integer.
4. The system validates the input.
5. The system identifies capital cities through country capital references.
6. The system retrieves eligible capital city population data.
7. The system sorts the results by population in descending order.
8. The system displays up to N capital cities.

## 6. Alternative and Exception Flows

- **A1:** N is empty, non-numeric, zero, or negative. The system requests a positive integer.
- **A2:** Fewer than N eligible capital cities exist. The system displays all eligible results.
- **A3:** No eligible capital cities exist. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N capital city report is displayed, or an appropriate message is provided.
