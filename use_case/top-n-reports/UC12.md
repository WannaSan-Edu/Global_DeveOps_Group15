# UC12: Top N Populated Cities in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC12 |
| Use Case Name | Top N Populated Cities in the World |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated cities worldwide.

## 3. Preconditions

The system and database are available, and city population data exists.

## 4. Trigger

The user selects the worldwide top-populated-cities report.

## 5. Main Success Flow

1. The user selects the report.
2. The system requests N.
3. The user enters a positive integer.
4. The system validates the input.
5. The system retrieves eligible city records.
6. The system sorts cities by population in descending order.
7. The system returns up to N cities.
8. The system displays the results.

## 6. Alternative and Exception Flows

- **A1:** N is empty, non-numeric, zero, or negative. The system requests a positive integer.
- **A2:** Fewer than N eligible cities exist. The system displays all eligible cities.
- **A3:** No eligible cities exist. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The requested top-N city report is displayed, or an appropriate message is provided.
