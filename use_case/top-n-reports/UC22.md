# UC22: Top N Populated Capital Cities in a Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC22 |
| Use Case Name | Top N Populated Capital Cities in a Region |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated capital cities associated with countries in a selected region.

## 3. Preconditions

The system and database are available, and the required regional and capital city data exists.

## 4. Trigger

The user selects the top-N capital-cities-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available regions.
3. The user selects a region.
4. The system requests N.
5. The user enters a positive integer.
6. The system validates the inputs.
7. The system identifies capital cities belonging to countries in the selected region.
8. The system sorts eligible cities by population in descending order.
9. The system displays up to N capital cities.

## 6. Alternative and Exception Flows

- **A1:** Invalid region or N. The system requests valid input.
- **A2:** Fewer than N eligible capital cities exist. The system displays all eligible results.
- **A3:** No matching capital cities exist. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N capital city report for the selected region is displayed, or an appropriate message is provided.
