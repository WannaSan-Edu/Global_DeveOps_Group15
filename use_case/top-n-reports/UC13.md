# UC13: Top N Populated Cities in a Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC13 |
| Use Case Name | Top N Populated Cities in a Continent |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated cities within a selected continent.

## 3. Preconditions

The system and database are available, and geographical and city population data exists.

## 4. Trigger

The user selects the top-N cities-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available continents.
3. The user selects a continent.
4. The system requests N.
5. The user enters a positive integer.
6. The system validates the inputs.
7. The system retrieves eligible cities in the selected continent.
8. The system sorts the results by population in descending order.
9. The system displays up to N cities.

## 6. Alternative and Exception Flows

- **A1:** Invalid continent or N. The system requests valid input.
- **A2:** Fewer than N eligible cities exist. The system displays all eligible cities.
- **A3:** No eligible cities exist. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N city report for the selected continent is displayed, or an appropriate message is provided.
