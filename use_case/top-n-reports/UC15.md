# UC15: Top N Populated Cities in a Country

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC15 |
| Use Case Name | Top N Populated Cities in a Country |
| Category | Top-N Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display the N most populated cities within a selected country.

## 3. Preconditions

The system and database are available, and country and city records exist.

## 4. Trigger

The user selects the top-N cities-by-country report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available countries.
3. The user selects a country.
4. The system requests N.
5. The user enters a positive integer.
6. The system validates the inputs.
7. The system retrieves cities associated with the selected country.
8. The system sorts cities by population in descending order.
9. The system displays up to N cities.

## 6. Alternative and Exception Flows

- **A1:** Invalid country or N. The system requests valid input.
- **A2:** Fewer than N eligible cities exist. The system displays all eligible cities.
- **A3:** No matching cities. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The top-N city report for the selected country is displayed, or an appropriate message is provided.
