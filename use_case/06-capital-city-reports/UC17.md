# UC17: All Capital Cities in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC17 |
| Use Case Name | All Capital Cities in the World |
| Category | Capital City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display capital cities and their associated countries, including available population information.

## 3. Preconditions

The system and database are available, and country and city records exist.

## 4. Trigger

The user selects the all-capital-cities report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country records and their capital city identifiers.
3. The system matches capital identifiers with the corresponding city records.
4. The system retrieves capital city names, country names, and city populations.
5. The system sorts the results by city population in descending order.
6. The system displays the report.

## 6. Alternative and Exception Flows

- **A1:** No capital city records are available. The system displays a no-results message.
- **A2:** A country has no valid capital reference. The system handles the missing reference without incorrectly identifying another city as its capital.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The capital city report is displayed, or an appropriate message is provided.
