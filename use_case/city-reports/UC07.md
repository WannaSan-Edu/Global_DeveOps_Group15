# UC07: All Cities in the World

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC07 |
| Use Case Name | All Cities in the World |
| Category | City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display all cities recorded in the database with their country, district, and population information.

## 3. Preconditions

The system and database are available, and city records exist.

## 4. Trigger

The user selects the all-cities report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves city records from the `City` table.
3. The system retrieves associated country information where required.
4. The system sorts cities by population in descending order.
5. The system displays the city name, country, district, and population.

## 6. Alternative and Exception Flows

- **A1:** No city records are available. The system displays a no-results message.
- **E1:** Database connection or query failure. The system displays an appropriate error message.

## 7. Postconditions

The city report is displayed, or an appropriate message explains why it cannot be generated.
