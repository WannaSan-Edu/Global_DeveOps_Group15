# UC10: Cities by Country

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC10 |
| Use Case Name | Cities by Country |
| Category | City Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display cities belonging to a selected country.

## 3. Preconditions

The system and database are available, and country and city records exist.

## 4. Trigger

The user selects the cities-by-country report.

## 5. Main Success Flow

1. The user selects the report.
2. The system displays available countries.
3. The user selects a country.
4. The system validates the selection.
5. The system retrieves cities associated with the selected country code.
6. The system sorts the cities by population in descending order.
7. The system displays the results.

## 6. Alternative and Exception Flows

- **A1:** Invalid country selection. The system requests a valid country.
- **A2:** No cities found for the selected country. The system displays a no-results message.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The cities belonging to the selected country are displayed, or an appropriate message is provided.
