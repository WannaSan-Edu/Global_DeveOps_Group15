# UC24: Population Distribution by Region

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC24 |
| Use Case Name | Population Distribution by Region |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To display population distribution information for each region.

## 3. Preconditions

The system and database are available, and country and city population data exists.

## 4. Trigger

The user selects the population-distribution-by-region report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country population data grouped by region.
3. The system calculates total country population for each region.
4. The system calculates recorded city population totals for each region.
5. The system calculates non-city population estimates where supported by the data.
6. The system calculates the relevant percentages using the agreed calculation rules.
7. The system displays the population distribution report.

## 6. Alternative and Exception Flows

- **A1:** No population data is available. The system displays a no-results message.
- **A2:** Population data is incomplete. The system identifies the missing information and avoids unsupported calculations.
- **A3:** A total population value is zero. The system avoids division by zero.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The population distribution report is displayed with the available data and supported calculations.
