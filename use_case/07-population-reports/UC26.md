# UC26: World Population

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC26 |
| Use Case Name | World Population |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To calculate and display the total population represented by the countries in the database.

## 3. Preconditions

The system and database are available, and country population data exists.

## 4. Trigger

The user selects the world-population report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country population values.
3. The system validates the available population data.
4. The system calculates the sum of the eligible country population values.
5. The system displays the calculated total and identifies the data source.

## 6. Alternative and Exception Flows

- **A1:** No country population records are available. The system displays a no-results message.
- **A2:** Some population values are missing or invalid. The system handles incomplete records according to the agreed reporting rules.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The calculated population total represented by the database is displayed, or an appropriate message is provided.

## 8. Calculation Note

The result represents the sum of the eligible country population records in the database. It should not automatically be treated as the current real-world population.
