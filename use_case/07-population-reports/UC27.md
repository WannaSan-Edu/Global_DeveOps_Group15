# UC27: Population by Continent

## 1. Use Case Information

| Field | Description |
|---|---|
| Use Case ID | UC27 |
| Use Case Name | Population by Continent |
| Category | Population Reports |
| Primary Actor | Organisation User |
| Supporting System | MySQL `world` Database |

## 2. Goal

To calculate and display the total recorded country population for each continent.

## 3. Preconditions

The system and database are available, and continent and country population data exists.

## 4. Trigger

The user selects the population-by-continent report.

## 5. Main Success Flow

1. The user selects the report.
2. The system retrieves country population data.
3. The system groups countries by continent.
4. The system calculates the sum of eligible country population values for each continent.
5. The system displays each continent and its calculated population total.

## 6. Alternative and Exception Flows

- **A1:** No eligible population records are available. The system displays a no-results message.
- **A2:** Population values are missing or invalid. The system handles incomplete data according to the agreed rules.
- **E1:** Database failure. The system displays an appropriate error message.

## 7. Postconditions

The population totals for the available continents are displayed.
